ChatPET

Turn your Muse Radio into a dedicated Codex Desktop companion: a native 320 × 240 pet display, stereo USB speaker and microphones, and physical controls, all through one USB cable.

  • Codex's native animated pet, activity bubble, and Live Orb
  • Stereo USB audio output and microphone input
  • Physical volume, dictation, navigation, and Codex controls
  • No Wi-Fi connection or password required at runtime

Windows 10 or Windows 11 and Codex Desktop are required. macOS support is planned.

Installation has two steps: use the button below to flash the Muse Radio firmware, then download the matching Windows software, extract the ZIP completely, and run INSTALL_WINDOWS.cmd. The web flasher cannot install the Windows display driver or ChatPET bridge.

Before flashing: this replaces the current Muse Radio firmware and its saved settings. Radio, Wi-Fi, Spotify, and AirPlay are not available while ChatPET is installed.

If the Muse Radio does not appear in the browser, keep the USB cable connected. Hold BOOT, press and release RESET, wait for the Windows reconnect sound, then release BOOT. Click Install again and select the Espressif device.
