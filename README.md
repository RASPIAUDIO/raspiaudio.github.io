# Squeezelite-ESP32 Installer

This the code for the Raspiaudio Ompen Source App Store  https://raspiaudio.github.io/

## Voice DSP+ V2 USB Recovery

[ZeroCore S3 / USB Recovery (Beta)](https://apps.raspiaudio.com/#device=ZeroCoreS3&application=USBRecovery)
restores XMOS USB access without Home Assistant or Wi-Fi, then links to the USB
updater for persistent installation. See the [guide and limits](ZeroCoreS3/USBRecovery/README.md).


# ESP32-S31 experimental installer

[S31 - Squeezelite (experimental)](https://raspiaudio.github.io/S31/Squeezelite/)
includes USB Wi-Fi setup with Improv Serial after flashing. See
[release notes and test status](S31/Squeezelite/README.md).
