S31 - Squeezelite (experimental)

Turn your ESP32-S31-Function-CoreBoard-1 into an Ethernet and Wi-Fi audio player.

Install and connect to Wi-Fi

  1. Use Chrome or Edge on a computer. Connect the board's USB UART port with a data cable and close serial monitors.
  2. Click Connect, select the CP210x USB serial port, then choose Install. Keep this tab open until installation finishes.
  3. Click Next to configure Wi-Fi using Improv Serial. Select Join other if your network is not listed, then enter its name and password.
  4. Open the device URL shown after connection. Ethernet can also be used directly.
USB installation requires Chrome or Edge on a computer.Open this page over HTTPS or localhost.

Before you start

For the 16 MB flash / 16 MB PSRAM Function-CoreBoard-1 only. This is not the original ESP32 MnCast firmware. Installation replaces the firmware and partition table, while retaining this S31 firmware's settings. Use a dedicated development board with the documented partition layout.

A fresh installation uses the onboard ES8311 and amplifier. External Audio+ V3 DAC wiring and an SPI display must be configured separately. Improv Serial is enabled by default and can be disabled under System → USB Wi-Fi setup.

New feature to test: Improv Serial

Wi-Fi credentials are sent locally over USB. This release does not use BLE provisioning. If USB setup is unavailable, the existing Wi-Fi access point and captive portal remain available.

Spotify Connect playback is still under investigation. Browser setup is experimental; see the validation notes for exactly what has been tested.
