I2S Firmware: 48 kHz, host-controlled

Install the accepted XMOS I2S application without changing its AEC processing. Installation through Safe Mode and I2S startup have been tested.

I2S is not a USB sound card. An I2S host must initialize audio. With Safe Mode 0.5.7 provisioned, USB recovery remains available for five seconds at each power-on. Connect the updater during that window to install USB or I2S without ZeroCore.

For initial provisioning, use Safe Recovery on ZeroCore S3 once. An application-only DFU update does not add Safe Mode to an older board.

For Home Assistant, choose Home Assistant (ZeroCore S3) instead: its ESP32 installer already includes its XMOS image. For Raspberry Pi, use the complete Pi kit with its qualified image and host settings; this newer UI2 image is not a replacement Pi qualification.
