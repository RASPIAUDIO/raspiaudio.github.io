I2S Firmware: 48 kHz, host-controlled

Install the accepted XMOS I2S application used by the current Home Assistant package, without changing its AEC processing. The new USB-to-I2S update package still needs hardware installation qualification.

After installation, USB audio and browser updating disappear. An I2S host must initialize audio. Returning to USB requires the ZeroCore recovery loader or Raspberry Pi/SPI provisioning.

For Home Assistant, choose Home Assistant (ZeroCore S3) instead: its ESP32 installer already includes its XMOS image. For Raspberry Pi, use the complete Pi kit with its qualified image and host settings; this newer UI2 image is not a replacement Pi qualification.
