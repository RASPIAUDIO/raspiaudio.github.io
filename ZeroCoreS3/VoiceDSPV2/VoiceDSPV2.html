ZeroCore S3 + Voice DSP+ V2

Home Assistant satellite, validated release 0.6.75 r8. Remembers your audio output, restores idle DOA and timer feedback, and adds BLE Wi-Fi setup. Outputs, Inputs, Assistant and Diagnostic controls stay on the native device page. No additional dashboard.

First installation on a blank or USB-only XMOS: run Voice DSP+ V2 Safe Recovery (I2S) first, then reinstall this Home Assistant firmware on the ZeroCore. This release normally starts the existing persistent XMOS I2S image, without reloading it at every boot.

Modes and filter changes apply automatically when audio is idle. Source, installation and settings-preservation checks pass. AEC, XMOS, wake models and crossover tuning are unchanged; no new acoustic qualification is claimed.

New: fast PAJ recovery, selectable Hey Jarvis / Okay Nabu / Hey Mycroft, contextual Action button, adjustable LED color/brightness and volume gauge, Voice PE sounds and timer animations. The accepted mono AEC settings are retained. Alternate wake words and spoken Stop during replies still need acoustic qualification.

V2 hardware only: RASPIAUDIO ZeroCore S3 (16 MB flash, 8 MB octal PSRAM) connected to a Voice DSP+ V2 shield. Do not use this image on V1 or Satellite1 hardware.

  1. Assemble the boards with power disconnected. Connect a USB data cable to the ZeroCore S3, not the XMOS USB port, and power the shield appropriately.
  2. Use Chrome or Edge on a desktop computer. Click Connect below and install. Erasing also removes saved Wi-Fi and settings.
  3. After installation, press RESET once if needed (do not hold BOOT). Configure 2.4 GHz Wi-Fi through serial Improv, or BLE Improv with a compatible nearby client. BLE opens for ten minutes when no Wi-Fi is saved, and switches off after setup. Home Assistant needs working Bluetooth or compatible provisioning support.
  4. Add the new ESPHome device in Home Assistant. Its network name is voicedsp-v2-xxxxxx, with a unique suffix for each board. Select your Assist pipeline.
  5. Wait for Diagnostic - XMOS firmware status: Ready. Choose Voice Compact / Full Speaker / Custom; the mode applies when audio is idle. Use Outputs - Audio Output and start at low main volume.

Routine boots resume the persistent XMOS I2S firmware. Install XMOS in Flash is a separate, explicit persistent installation action; Reload embedded XMOS firmware is a temporary RAM recovery action. The ZeroCore stays connected for Home Assistant. Validated AEC and crossover values are unchanged.

Known beta limitation: an I2C bus lock has been observed. If the controller stays unavailable, disconnect all power to both boards for 10 seconds. Recovery was observed, but long-term stability is not qualified. Power-Good remains diagnostic only; this build does not enforce power limits.

Includes local Hey Jarvis, Assist, media, gestures enabled by default, LED/sound feedback, output selection, bass/treble and diagnostics. Internal and external general gains are 0 dB and hidden by default; use the main volume control. PAJ Motion means a recent gesture, not occupancy. PD Power means available negotiated power, not measured consumption.

External / Full Speaker: connect a USB-C Power Delivery supply directly to Voice DSP+ (65 W or more recommended). Do not connect a second power supply through the shared header. Full Speaker uses L woofer / R tweeter with a matched crossover; never select unfiltered External for a bare tweeter.

Wake word runs on ESP32; XMOS handles four-microphone processing and AEC. Home Assistant handles speech recognition and responses. This release retains opt-in capture diagnostics and unencrypted local API/OTA: use a trusted LAN, not Internet-exposed ports.

In Home Assistant, Diagnostic - ESP32 + XMOS Firmware offers r8 on stable and beta channels. Checks run at startup and every six hours, or use Diagnostic - Check firmware updates. Installation stays manual; no ESPHome server is needed. This update changes ESP32 software, not the installed XMOS/AEC. Future XMOS updates need their documented persistent-install step; a catalog check alone never flashes XMOS.
