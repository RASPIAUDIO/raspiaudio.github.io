ZeroCore S3 + Voice DSP+ V2

Home Assistant satellite, beta 0.6.54. One ESP32 installation includes the matching XMOS firmware. No XTAG needed.

V2 hardware only: RASPIAUDIO ZeroCore S3 (16 MB flash, 8 MB octal PSRAM) connected to a Voice DSP+ V2 shield. Do not use this image on V1 or Satellite1 hardware.

  1. Assemble the boards with power disconnected. Connect a USB data cable to the ZeroCore S3, not the XMOS USB port, and power the shield appropriately.
  2. Use Chrome or Edge on a desktop computer. Click Connect below and install. Erasing also removes saved Wi-Fi and settings.
  3. After installation, press RESET once if needed (do not hold BOOT). Configure your 2.4 GHz Wi-Fi through the installer's serial Improv setup. Bluetooth provisioning is not included.
  4. Add the new ESPHome device in Home Assistant. Its network name is voicedsp-v2-xxxxxx, with a unique suffix for each board. Select your Assist pipeline.
  5. Wait for Audio Controller Ready and XMOS SPI Boot: Ready. Choose internal stereo, external speaker, or jack in Sortie audio. Start at low volume.

The XMOS image is stored inside the ESP32 firmware and loaded into XMOS RAM automatically at every ESP32 startup. This does not program XMOS QSPI; the ZeroCore must remain connected.

Known beta limitation: an I2C bus lock has been observed. If the controller stays unavailable, disconnect all power to both boards for 10 seconds. Recovery was observed, but long-term stability is not qualified. Power-Good remains diagnostic only; this build does not enforce power limits.

Includes local Hey Jarvis, Assist, media, gestures, LED feedback and the external-mono AEC profile. The private audio capture server is removed. Microphone audio is sent to your configured Home Assistant pipeline during an activated request.

In Home Assistant, use Reload embedded XMOS firmware to restart with the bundled image, or ESP32 + XMOS Firmware to install a new paired release. Updates are manual. Loading progress reaches 100% only when the controller responds.
