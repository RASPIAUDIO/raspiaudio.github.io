Bring USB back.

Install USB Recovery from the App Store first, then power-cycle both boards. This page reads the ZeroCore log; it does not flash XMOS or start playback.

Close the ESP installer and other serial monitors before connecting. Select the ZeroCore S3 serial port, not the XMOS audio device.

Waiting for ZeroCore.


  
The log must identify VOICE_DSP_V2_USB_RECOVERY_0.1.0. If it identifies the factory tester or another app, reinstall USB Recovery.

  
A successful SPI transfer is only the first step. The USB updater must detect XMOS with DFU and complete installation. Then power off, remove ZeroCore, and check autonomous USB startup.
