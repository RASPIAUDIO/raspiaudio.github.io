Voice DSP+ V2 Safe Recovery - USB / I2S

Install once with ZeroCore S3. Switch USB / I2S later using only the XMOS USB port.

Version 0.5.7 permanently installs a USB recovery window and the validated I2S 48 kHz application in XMOS flash. At each power-on, USB recovery is available for five seconds, then I2S starts by default. Connecting the USB updater during this window keeps recovery open.

ZeroCore S3 + Voice DSP+ V2 only. Replaces the ESP32 application and the lower XMOS boot partition. Upper flash settings, AEC and filter algorithms are preserved. Stop playback and disconnect speakers during provisioning.

  1. With all power off, mount ZeroCore S3 on the Voice DSP+ V2 40-pin header. Connect ZeroCore USB data to your PC.
  2. Install this app below, choosing erase for a clean installation. Close the ESP32 installer.
  3. Disconnect all power for ten seconds, then reconnect both USB data cables. Provisioning starts automatically and takes several minutes. Do not reset or disconnect while writing.
  4. Read recovery status and wait for INSTALL_QSPI_VERIFIED. A RAM transfer alone is not a successful installation.
  5. Power off, remove ZeroCore, then power the Voice DSP+ again. Recovery appears for five seconds, then the installed I2S firmware starts. I2S needs its normal host to initialize audio; it is not a USB sound card.

Choose USB sound card or I2S afterwards

Open the XMOS USB updater first. Power-cycle the Voice DSP+, click Connect and select Voice DSP+ USB Recovery 5s within the window. Choose USB or I2S and install. Once connected, you do not need to finish flashing within five seconds. If you miss the window, power-cycle and try again.

No ZeroCore, XTAG, Wi-Fi or Home Assistant is needed for these later updates. Use the recovery window for reliable switching; a transfer from the running USB audio application failed during qualification and was recovered through Safe Mode.

The ZeroCore remembers successful provisioning and skips the same bundle after reset. For a different board, erase/reinstall this ESP32 app first. The Factory Check tester is separate and is not installed by this app.
