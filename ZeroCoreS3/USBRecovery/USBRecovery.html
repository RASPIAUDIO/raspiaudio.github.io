Voice DSP+ V2 USB Recovery

Restore the XMOS USB interface with ZeroCore S3. No Home Assistant, Wi-Fi or XTAG.

This temporary recovery tool loads the accepted USB mono 48 kHz firmware 0.8.9-r4 into XMOS RAM. Then use the USB updater to install the persistent upgrade.

ZeroCore S3 + Voice DSP+ V2 only. Installing replaces the ESP32 application (including the factory tester or Home Assistant). It does not erase or program XMOS QSPI. Stop playback and disconnect speakers for recovery: the restored USB runtime may restore saved output/volume settings.

  1. With all power disconnected, attach ZeroCore S3 to the V2 40-pin header. Connect the ZeroCore USB data port to your PC.
  2. Click Connect below and install the recovery app. Select erase for a clean recovery installation. Close the installer when complete.
  3. Disconnect all power to both boards for 10 seconds. Reconnect their USB data cables to the PC, without XTAG. Recovery starts automatically; wait about 15 seconds. If the ESP32 remains in download mode, press RESET once without BOOT.
  4. Open recovery status if you need the ZeroCore log. A completed SPI transfer is not yet proof that XMOS USB is running.
  5. Keep power connected. Open the XMOS USB updater, connect the XMOS USB port and install the recommended V2 USB firmware. Do not select V1.
  6. After a successful USB update, power off, remove ZeroCore and reconnect only Voice DSP+ USB. Check that it boots autonomously before reconnecting speakers.

Scope: this restores USB access on a V2 with an existing compatible QSPI factory layout. It is not a complete factory programmer for blank/corrupt QSPI. Those boards need initial factory provisioning; an upgrade alone is not enough.

Beta status: compiled and software-checked; based on the tested SPI loader. This new combined installer has not yet been tested end-to-end on hardware. Firmware audio/AEC settings were not changed.
