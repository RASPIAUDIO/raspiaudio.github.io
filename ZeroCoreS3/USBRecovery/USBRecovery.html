Voice DSP+ V2 USB Recovery

Restore the XMOS USB interface with ZeroCore S3. No Home Assistant, Wi-Fi or XTAG.

This recovery app installs USB mono 48 kHz 0.8.9-r4 permanently in XMOS flash. ZeroCore is needed only for installation; afterwards Voice DSP+ can start by itself. No second USB-flasher step is required.

ZeroCore S3 + Voice DSP+ V2 only. This replaces the ESP32 application AND the XMOS boot firmware. The upper flash settings area is preserved. Stop playback and disconnect speakers: USB may restore previously saved output/volume settings.

  1. With all power disconnected, attach ZeroCore S3 to the V2 40-pin header. Connect the ZeroCore USB data port to your PC.
  2. Click Connect below and install the recovery app. Select erase for a clean recovery installation. Close the installer when complete.
  3. Disconnect all power to both boards for 10 seconds. Reconnect their USB data cables to the PC, without XTAG. Installation starts automatically and takes several minutes. If the ESP32 stays in download mode, press RESET once without BOOT before installation begins.
  4. Open recovery status and wait for INSTALL_QSPI_VERIFIED. Keep power connected throughout erase, write and readback. A RAM transfer alone does not mean installation succeeded.
  5. After verification, power off both boards, physically remove ZeroCore from the header, and connect only the Voice DSP+ USB data port. Check standalone USB detection before reconnecting speakers.

Scope: a complete USB factory image is written to supported V2 4 MB flash, including when the old boot image is missing or corrupt. The factory microphone tester remains a separate app. Audio processing, AEC and filters are unchanged.

For later updates, use the XMOS USB updater directly, without ZeroCore.
