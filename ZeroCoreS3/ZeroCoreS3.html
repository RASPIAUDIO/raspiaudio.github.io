ZeroCore S3

An ESP32-S3 controller for a Voice DSP+ Home Assistant voice satellite or a Digital Radio receiver.

Fit the shield required by your chosen application to the 40-pin header, then use the ZeroCore S3 USB-C data port to install its firmware.

Choose the matching hardware: Voice DSP+ for Home Assistant, or the SI4689 Digital Radio shield for FM and DAB+. An installation replaces the current ESP32 application.

Only have the Voice DSP+ USB board? Use the XMOS USB audio firmware loader instead.
