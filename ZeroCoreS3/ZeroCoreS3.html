ZeroCore S3

The ESP32-S3 base for your Voice DSP+ Home Assistant voice satellite.

Connect Voice DSP+ to the 40-pin header, then use the ZeroCore S3 USB-C data port to install the application. The ESP32 manages the XMOS audio processor for you.

Requires both boards: ZeroCore S3 (16 MB flash, 8 MB octal PSRAM) and Voice DSP+. This is not the USB sound-card firmware and does not install Home Assistant OS.

Only have the Voice DSP+ USB board? Use the XMOS USB audio firmware loader instead.
